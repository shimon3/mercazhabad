לאחר הזנת הסיסמה, יש להזין קוד מאפליקציית האימות.

אימות דו־שלבי

סרקו את קוד ה־QR באפליקציית Microsoft Authenticator או Google Authenticator. הקוד נוצר במכשיר שלכם ואינו נשלח לאתר חיצוני.

ב־Microsoft Authenticator בחרו + ← חשבון אחר ← סריקת קוד QR.

המפתח סודי. אין לשלוח אותו, לשתף צילום מסך או לשמור אותו במסמכים משותפים.
